---

## 总览

```text
一期  工具导航 MVP（可引流、可挂链）
二期  优惠 + 内容联动 + 点击统计
三期  自研小工具 MVP（商品描述生成器）
四期  会员 / 广告 / 更多小工具
```

旧「作品展映 / 创作者社区」路线废弃；相关代码可保留但退出主导航。

---

## 一期 · 工具导航 MVP

**目标：** 站点主叙事变为「找 AI 工具」。

| 项 | 内容 |
|----|------|
| 数据 | Tool、Category/Tag；Admin 上下架与置顶 |
| 前台 | 首页改版、工具列表/详情、搜索接入工具 |
| 链接 | 官网 / Affiliate 字段可配置 |
| 内容 | 文章可挂 `relatedToolIds`（可先手工） |
| 降权 | 项目 / 关注等退出主导航 |

**成功：** 访客能按分类找到工具并点到外链；运营能在后台维护工具库。

---

## 二期 · Deal + 统计 + 评测联动

| 项 | 内容 |
|----|------|
| Deal | 限时优惠列表与详情跳转；过期处理 |
| 统计 | 工具 / Deal 点击日志（支撑合作报价） |
| 内容 | 评测模板与工具卡片组件 |
| SEO | 工具页 / 评测页基础 meta |

**成功：** 有「今日优惠」入口；点击可查。

---

## 三期 · AI 小工具 MVP

| 项 | 内容 |
|----|------|
| 平台 | `AiMiniTool` 配置 + `/api/ai-tools/{slug}/run` + 日配额 |
| 首发 | 商品描述生成器 |
| 转化 | 未登录低额度 → 登录 / 引导会员页（会员能力可先占位） |

**成功：** 稳定生成；配额挡住滥用。

---

## 四期 · 变现加深

| 项 | 内容 |
|----|------|
| 会员 | 额度与精选内容包（支付可先人工） |
| 广告 | 流量够再接 |
| 小工具 | 简历优化器；合同类极晚且仅风险提示 |
| 对比 | 工具对比页（可选） |

---

## 明确不做（近端）

- 复杂商家入驻与自动结算  
- 重社交与 Agent 平台  
- 合同正式审查结论
