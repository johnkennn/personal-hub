## P0 · 壳与体验基线 ✅

**目标：** 站点看起来、用起来像 AI 产品入口。

| 项 | 内容 |
|----|------|
| IA | 顶栏：聊天、发现、AI导航、AI评测、限时优惠、关于 |
| 默认页 | `/` = 聊天；发现 = `/discover`；品牌进聊天 |
| 聊天 | 左侧模式栏；默认「聊天检索」（问答+导流+模糊搜）；技能对话框内完成；session 持久化 |
| 技能清单 | 文案写作 · 翻译 · 简历 · 图像生成 · 图片识别 · 视频理解 · **内容总结（Word/Excel/PPT/PDF）** · 合同助手 |
| 搜索 | **无顶栏搜索**；检索在聊天检索模式，回复可点击列表 |
| 文案 / 视觉 / 关于 | 用户向；联系仅管理员手机 |

**验收：** 访客打开即聊天；无工程黑话；手机可点通各栏。→ **已满足，作为开发基线。**

---

## P1 · 双轨可用（正式开发 · 当前）

**目标：** 「找得到产品」且「对话里能办成一件事」。

| 轨 | 交付 |
|----|------|
| **AI导航** | Tool + Category；Admin CRUD；公开列表/详情；官网 / Affiliate；分类筛选 |
| **聊天·文案** | AiClient + `copywriting`/`product-desc` 技能；对话内生成；日配额 + AiRunLog；优先流式 |
| **聊天** | 意图覆盖主板块；办事引导切技能；可接真模型问答（可选同迭代） |
| **发现** | 热门 Tool、技能入口、精选评测接真数据 |
| **搜索** | 目录检索接真实 Tool 名（替换/补充种子数据） |

**验收：**

1. 运营可上架真实工具，访客能分类浏览并点到外链。  
2. 「文案写作」模式可在对话内生成可用草稿；配额生效。  
3. 聊天导流与顶部目录检索分工清晰。  
4. 移动端上述路径可完成。

**建议开工顺序：** ① Tool 库表/API/Admin → ② 前台导航列表详情 → ③ AiClient + 文案技能 → ④ 发现与搜索接真数据。

## P2 · 转化与内容闭环

| 项 | 交付 |
|----|------|
| 限时优惠 | Deal CRUD、列表、过期、发现入口 |
| 点击统计 | 跳转计数 + Admin 可查 |
| 评测联动 | relatedToolIds；文内工具卡片；SEO |
| 技能加深 | **内容总结**（文档解析 + 上传）；翻译 / 简历等择优 |
| 体验 | SSE 流式打磨；收藏 Tool |

**验收：** 有进行中优惠；外链可统计；内容总结可对 PDF/Word 等出要点（有大小限制）。
