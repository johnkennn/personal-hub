## P0 · 壳与体验基线 ✅

**目标：** 站点看起来、用起来像 AI 产品入口。

| 项 | 内容 |
|----|------|
| IA | 顶栏：小智、发现、AI导览、AI评测、限时优惠、关于 |
| 默认页 | `/` = 小智；发现 = `/discover`；品牌进小智 |
| 聊天（历史） | 曾用左侧模式栏；**现已升级为统一对话（见 P1）** |
| 搜索 | **无顶栏搜索**；检索在小智内 |
| 文案 / 视觉 / 关于 | 用户向；联系仅管理员手机 |

**验收：** 访客打开即小智；无工程黑话；手机可点通各栏。→ **已满足。**

---

## P1 · 双轨可用（正式开发 · 当前）

**目标：** 「找得到产品」且「对话里能办成一件事」。

| 轨 | 交付 | 状态 |
|----|------|------|
| **AI导览** | Tool + Category；Admin CRUD；公开列表/详情；分类筛选 | ✅ 基本完成 |
| **统一聊天** | 去掉侧栏；规则意图 + 追问；生成类统一大模型；sessionStorage | ✅ 完成 |
| **品牌** | 小智AI + logo；助手自称小智 | ✅ |
| **附件** | 白名单 + 大小；临时上传 `/api/chat/attachments`；识图 | ✅ |
| **配额** | 访客 3 / 登录 30；页内剩余额度；SSE 429 | ✅ |
| **优惠门禁** | 列表需登录；页内直跳登录 | ✅ |
| **发现 / 搜索** | 热门 Tool、目录检索接 API | ✅ 基本完成 |
| **聊天门面** | `POST /api/chat/stream` | ✅ |

**验收（更新）：**

1. 运营可上架工具，访客能分类浏览并点外链。  
2. 小智内可搜产品、大模型流式回复；意图不清会追问（搜产品 / 大模型）。  
3. 无侧栏；关标签页对话消失（sessionStorage）。  
4. 访客额度用尽可引导登录；登录后额度提升；页内可见剩余次数。  
5. 移动端主路径可完成。

**建议后续顺序：** 运营校准优惠内容 → 点击统计 / 文档解析加深 → 会员分层。

## P2 · 转化与内容闭环

| 项 | 交付 |
|----|------|
| 限时优惠 | Deal CRUD、列表、过期、Admin；**前后端已落地**（运营在 Admin 录入） |
| 点击统计 | 跳转计数 + Admin 可查 |
| 评测联动 | relatedToolIds；文内工具卡片；SEO |
| 技能加深 | **内容总结**（服务端解析 PDF/Office + 临时文件 TTL）；合同助手 |
| 体验 | 断线取消上游模型请求；收藏 Tool |
| 配额 | 接真模型后开启并校准访客/登录额度 |

**验收：** 有进行中优惠；外链可统计；内容总结可对 PDF/Word 等出要点（有大小限制）。

## 明确不做（近端）

- 整体重写前后端或换栈  
- 复杂商家入驻与自动结算  
- 重社交与实时 Agent 平台  
- 合同正式审查结论  
- 技能再拆独立顶栏 / **恢复侧栏为唯一入口**  
- 前台展示技术/排期黑话  
- 附件默认长期入库
