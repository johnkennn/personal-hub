# Personal Hub — 产品需求文档（PRD）

| 项目 | 说明 |
|------|------|
| 产品名称 | Personal Hub |
| 文档版本 | V1.0 |
| 状态 | Draft |

---

## 1. 项目目标

Personal Hub 是一个个人数字平台，用于展示个人信息、博客与项目作品。

同时作为长期实践项目，覆盖 React、Spring Boot、MySQL、Docker、Linux、CI/CD 等全栈技术的学习与落地。

**核心目标：**

- 对外：形成统一、可访问的个人品牌与作品展示入口
- 对内：跑通前后端分离、数据持久化、部署与持续集成的完整开发链路
- 长期：持续迭代，演进为可扩展的个人互联网应用

---

## 2. 目标用户

| 角色 | 描述 | 核心诉求 |
|------|------|----------|
| 访客 | 浏览个人主页的外部用户 | 了解作者、阅读文章、查看项目 |
| 管理员（本人） | 内容维护者 | 登录后台，管理文章与项目 |

V1 仅支持单管理员，不开放公开注册。

---

## 3. 功能范围（V1）

### 3.1 范围内（In Scope）

#### 前台

| 模块 | 说明 |
|------|------|
| 首页 | 个人品牌入口，概览介绍、精选内容入口 |
| 关于我 | 个人简介、技能、经历等静态/半静态信息展示 |
| 博客 | 文章列表、文章详情；支持按时间浏览 |
| 项目展示 | 项目列表、项目详情（简介、技术栈、链接等） |

#### 后台

| 模块 | 说明 |
|------|------|
| 后台登录 | 管理员账号密码登录，会话鉴权 |
| 文章管理 | 文章的增删改查、发布/下架 |
| 项目管理 | 项目的增删改查、展示/隐藏 |

### 3.2 范围外（Out of Scope）

以下内容不在 V1 交付范围内：

- 用户注册 / 多用户体系
- 评论、点赞、分享
- 全文搜索、标签筛选（可放入后续迭代）
- 文件/图片 CDN、复杂媒体库
- 多语言、主题切换
- 数据分析看板

---

## 4. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 首屏可接受加载；列表页常规数据量下响应流畅 |
| 可用性 | 桌面与移动端均可正常浏览前台页面 |
| 安全 | 后台接口需鉴权；密码不明文存储；防常见注入与越权 |
| 可维护性 | 前后端分离；代码与文档结构清晰，便于后续迭代 |
| 可部署性 | 支持本地开发；目标可容器化部署（Docker） |
| 技术栈 | 前端 React；后端 Spring Boot；数据库 MySQL；部署相关 Docker / Linux / CI/CD |

---

## 5. 未来规划

按优先级大致规划如下（非正式排期）：

| 阶段 | 方向 |
|------|------|
| V1.x | 标签/分类、草稿、封面图、基础 SEO |
| V2 | 评论、搜索、访问统计 |
| V3 | Redis 缓存、对象存储、更完善的 CI/CD 与监控 |
| 长期 | 可扩展能力（插件化内容类型、多站点/主题等） |

---

## 6. 成功标准（V1）

- 访客可完整浏览：首页、关于我、博客、项目
- 管理员可登录后台，完成文章与项目的 CRUD
- 前后端联调可用，数据持久化到 MySQL
- 具备后续 Docker / CI/CD 接入的基础工程结构
