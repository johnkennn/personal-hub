# 演示版前端能力包（无后端可演）

面向「功能强大且实用」的现场演示：在 API 不可用或数据为空时，用 mock + `localStorage` 跑通访客 → 互动 → 创作台 → 治理全流程。

## 已含能力

| 能力 | 说明 |
|------|------|
| 公开内容兜底 | 文章/项目列表与详情：请求失败或空列表时用演示数据 |
| 多创作者主页 | `/u/:id`：资料、作品、关注数、关注/取关 |
| 关注关系 | 本地持久化；首页「关注动态」Tab |
| 轻社交 | 详情页点赞、评论（未登录引导登录） |
| 搜索 | 顶栏搜索 / `⌘Ctrl+K` |
| Markdown | 详情渲染 + 写文章编辑/预览双 Tab |
| 封面条 | 列表卡片渐变封面，增强视觉密度 |
| 最热排序 | 文章列表按本地点赞数排序 |
| 阅读进度 | 文章详情顶部进度条 |
| 通知铃铛 | 顶栏动态通知（本地）；互动会写入 |
| 悬浮坞 | 回到顶部 + `?` 快捷键帮助 |
| 创作台持久化 | 草稿/发布列表操作刷新后仍保留（localStorage） |
| 建议箱 / 治理 | 批量发布、分页、管理员演示治理 |

## 演示话术顺序（建议 5–7 分钟）

1. 首页 Hero → 最新 → 切「关注动态」  
2. 打开 Markdown 文章 → 滚动看进度条 → 点赞/评论 → 看通知铃铛  
3. 点作者主页 → 关注 → 回首页看关注动态  
4. 文章列表切「最热」；顶栏搜索  
5. 登录 → 创作台批量发布 → 我的建议 → 内容治理
