| 项 | 说明 |
|----|------|
| 产品名称 | Personal Hub |
| 文档版本 | V1.0.0 |
| 状态 | Confirmed |
| 视觉方向 | 深色工作室风（青灰 + 苔绿强调），注重质感与动效 |

---

## 1. 产品定位

**一句话：** 面向创作者的多模块内容平台——写文章、晒项目，支持多作者与轻社交，并可扩展更多内容模块。

**不是什么：** 不只是个人博客壳子；也不是重型社交网络。

**长期形态：** 多作者 + 可插拔内容模块（文章 / 项目为前两个；后续可加笔记、资源等）。

| 受众 | 价值 |
|------|------|
| 创作者 | 清晰的草稿 → 发布 → 下架回草稿；头像与配图；被发现、被互动 |
| 访客 | 浏览已发布作品；点赞评论；关注感兴趣的创作者 |
| 平台 | 模块化扩展；开放注册利于冷启动引流 |

---

## 2. 角色与权限

| 角色 | 说明 | 能力 |
|------|------|------|
| 访客（未登录） | 任意浏览者 | 浏览已发布内容与公开主页；查看点赞数/评论列表；**不可**评论/点赞/关注（引导注册登录） |
| 创作者（已登录） | 注册用户 | 资料与头像；各模块「我的草稿 / 我的发布」；上传配图；点赞评论；关注/取关 |
| 平台管理员 | 运营账号 | 用户禁用；强制下架；评论治理 |

## 3. 模块化内容模型

```
ContentModule
  ├─ Article（文章）
  ├─ Project（项目）
  └─ （后续）Note / Resource / …
```

每个模块对每个创作者提供：

| 目录 | 含义 |
|------|------|
| **我的草稿** | 未公开发布；可编辑、可删除/批量删除、可发布 |
| **我的发布** | 公开展示中；**不可编辑**；可下架/批量下架、可删除/批量删除 |

### 3.1 状态机

```
新建 → DRAFT（草稿）
DRAFT ──发布──→ PUBLISHED（全站可见）
PUBLISHED ──下架──→ DRAFT（回到我的草稿，恢复可编辑）
DRAFT / PUBLISHED ──删除──→ 软删除（对外不可见，见 3.3）
```

### 3.2 硬规则

1. **已发布不可编辑**；修改必须先下架进入草稿。  
2. 下架后自动进入「我的草稿」。  
3. 仅 `PUBLISHED` 且未删除对访客可见。  
4. 草稿仅作者本人可见（管理员治理场景除外）。  
5. 「我的草稿 / 我的发布」均支持单删与批量删；「我的发布」另支持单下架与批量下架。  
6. 后端强制校验状态与所属用户，不依赖前端隐藏按钮。

### 3.3 为什么删除用软删除

批量删除、误操作在创作工具里很常见。软删除指：写入 `deleted_at`（或 `status=DELETED`），**对外与列表均不可见**，数据库行暂保留。

| 收益 | 说明 |
|------|------|
| 可恢复 | 误删后管理员或「回收站」（可后置）能恢复 |
| 可审计 | 纠纷、滥用时可追溯「曾经发过什么」 |
| 社交引用安全 | 评论/点赞挂在内容上时，硬删易造成大量孤儿数据 |

**对外表现与硬删一致：** 用户感觉就是删掉了。  
**建议策略：** 软删 + 定期清理任务（如 30 天后物理删除）兼顾隐私与磁盘；V1.0.0 可先只做软删，清理任务可同版本简单做或紧随补上。

> 若产品坚持「点删除即物理删除」，可改为硬删，但批量误删成本更高，需要更强的确认 UI。本 V1.0.0 **采用软删除**。

## 4. 功能模块

### 4.1 注册与账号（必含）

| 功能 | 细节 |
|------|------|
| 注册 | **开放注册**（邮箱或用户名 + 密码）；校验强度；注册/登录 **限流** 防刷 |
| 登录 / 登出 | JWT（或等价）；登出作废客户端令牌 |
| 个人资料 | 昵称、简介、外链 |
| 头像 | 用户上传；限制 jpg/png/webp、大小（如 ≤2MB） |
| 公开主页 | `/u/:id`：头像、昵称、简介、已发布作品、粉丝/关注数入口 |

### 4.2 关注 / 粉丝（V1.0.0 纳入）

| 功能 | 细节 |
|------|------|
| 关注 / 取关 | 登录用户关注其他创作者；不可关注自己 |
| 粉丝列表 | 谁关注了我 |
| 关注列表 | 我关注了谁 |
| 主页展示 | 展示关注数、粉丝数；列表可分页 |
| Feed 加分（建议做） | 首页可增加「关注的人」已发布动态 Tab（时间序）；若排期紧可先只做关系与列表，Feed Tab 作为同版本应做项 |

不做：私信、关注分组、密友圈。

### 4.3 发现与引流

| 功能 | 细节 |
|------|------|
| 首页 | 品牌 Hero + 最新已发布内容（文章/项目）；可选「关注动态」Tab |
| 文章 / 项目公开 Feed | 分页；按时间；可选按点赞简单排序 |
| SEO 基础 | 每页 title/description；基础 Open Graph |
| 关于/产品说明 | 说明平台用途，利于理解与传播 |

### 4.4 文章模块

| 功能 | 细节 |
|------|------|
| 公开列表 / 详情 | 标题、作者、时间、摘要/封面、Markdown 正文；底栏社交 |
| 我的草稿 | 编辑、删/批删、发布 |
| 我的发布 | 下架/批下架、删/批删；无编辑入口 |
| 新建 / 编辑 | 标题、Markdown 正文、配图；存草稿；支持预览 |

### 4.5 项目模块

与文章对称：名称、描述、技术栈、Repo/Demo、配图；同一套草稿/发布/批量规则。

### 4.6 媒体

| 功能 | 细节 |
|------|------|
| 上传场景 | 头像；文章/项目新建编辑页；详情页展示 |
| 约束 | 类型白名单、大小与数量上限 |
| 存储 | 服务器本地 + Nginx 暴露（见技术文档） |

### 4.7 轻社交（详情页底部）

| 功能 | 细节 |
|------|------|
| 点赞 | 登录用户对已发布内容点赞/取消；展示数量 |
| 评论 | **仅登录**可发评；作者可删自己的评论；管理员可删任意；分页 |
| 未登录 | 可浏览赞数与评论；CTA 引导注册/登录 |

不做：转发、@、表情回应扩展、通知中心完整版（可后续）。

### 4.8 创作台（Studio）

登录后统一工作台：

- 概览：各模块草稿数 / 已发布数、粉丝与关注摘要  
- 分模块：「我的草稿」「我的发布」  
- 快捷：写文章、建项目  

### 4.9 管理端（最小）

- 用户列表、禁用  
- 强制下架内容、删除违规评论  

### 4.10 体验

- 全站 **移动端适配**（导航收折、列表与表单可用）  
- 深色炫酷向视觉 + 克制动效  
- 统一空态 / 加载 / 错误 / 无权限  
- 批量删、批量下架需二次确认  

---

## 5. 关键用户流程

1. **访客** → 浏览 Feed/详情 → 注册登录 → 点赞评论 / 关注作者  
2. **创作者** → 注册 → 完善头像资料 → 新建（可传图）→ 草稿 → 发布  
3. **修改已发布** → 下架 → 草稿编辑 → 再发布  
4. **清理** → 批量下架或批量删除  

---

## 6. 范围边界

### In Scope（V1.0.0 必须）

- 开放注册、登录、资料、头像  
- 多作者  
- 文章 + 项目模块及统一状态机与批量操作  
- 关注 / 粉丝（含数量与列表；关注动态 Feed 为应做）  
- 图片上传与展示  
- 点赞 + 评论（登录互动）  
- 发现首页 + 深色 UI + 移动适配  
- 最小管理治理  

### Out of Scope

- 付费、广告系统、复杂推荐  
- 私信、实时聊天  
- 完整通知中心 / 邮件营销  
- 第三方 OAuth 登录（可 V1.1）  
- V1.0.0 内上线第三内容模块（模型预留即可）  
- 重型搜索引擎  

---

## 7. 成功标准

- ≥2 个创作者账号同时创作，草稿互不可见，已发布公开展示  
- 关注关系可用；详情可赞可评（需登录）  
- 头像与配图链路完整  
- 手机可完成：注册、浏览、关注、发草稿、发布、下架  
- 第三模块可在不推翻状态机的前提下扩展
