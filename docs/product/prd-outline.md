## 1. 产品定位

**一句话：** AI 工具导航与评测聚合站 + 少量自研 AI 小工具。

| 主 / 辅 | 模块 | 作用 |
|---------|------|------|
| **主** | 工具导航、分类、对比、限时优惠 | SEO / 引流；Affiliate、付费收录 |
| **辅** | 评测 / 教程文章 | 内容信任与内链 |
| **辅** | 自研 AI 小工具 | 留存、注册转化、会员钩子 |

**不是什么：** 不是重型社交；不是大而全 AI Agent 平台；不先做法务级「合同审查结论」。

**工程原则：** 复用现有 React + Spring Boot + MySQL + 鉴权 / Admin / 文章 / 媒体 / 搜索；新增 Tool / Deal / AiMiniTool 等领域模型。

---

## 2. 目标用户与角色

| 角色 | 诉求 |
|------|------|
| 访客 | 找工具、看评测与优惠、试用小工具（低额度） |
| 登录用户 | 更高小工具额度、收藏工具、提交收录建议 |
| 会员（后期） | 更高额度、精选包 / 教程、弱广告 |
| 运营管理员 | 工具与优惠上下架、置顶、审核、看点击与用量 |
| 工具方 / 商家 | 付费收录、置顶、活动合作（可先人工对接） |

## 3. 信息架构（站点）

```text
首页：搜索、分类入口、热门工具、今日优惠、自研工具、精选评测
工具导航：分类 / 筛选 / 详情 / 对比（对比可二期）
限时优惠：Deal 列表
评测与教程：复用文章（类型：评测 / 教程 / 榜单）
自研 AI 小工具：商品描述生成器（MVP）→ 简历优化器 → …
会员 / 合作：会员页；提交工具；商务合作（付费收录）
我的：收藏、额度、账号设置
Admin：工具、分类标签、Deal、小工具配置、点击/用量、用户与内容治理（精简）
```

**降权（非删除代码也可）：** 项目展映、关注 Feed 等创作者社区主路径退出主导航，避免定位打架。

## 4. 功能模块大纲

### 4.1 工具导航（P0）

- 分类浏览、标签筛选（免费 / 订阅 / API / 中文等）
- 工具详情：简介、评分摘要、优缺点、定价、官网 / Affiliate CTA
- 排序：编辑精选、权重、热度（点击）
- 状态：草稿 / 上架 / 下架；置顶与过期时间

### 4.2 限时优惠 Deal（P0～P1）

- 关联工具；文案、优惠码、有效期、跳转链接
- 列表展示进行中活动；过期不可点或自动隐藏

### 4.3 内容评测（P0）

- 复用 Article；扩展类型与 `relatedToolIds`
- 评测文内嵌工具卡片，导向详情 / 外链

### 4.4 自研 AI 小工具（P1）

- 统一执行：`POST /api/ai-tools/{slug}/run`
- 配置化：Prompt、模型、日配额、开关
- **MVP：** 商品描述生成器
- **二期：** 简历优化器（注意隐私，少持久化）
- **更晚：** 合同类仅「风险提示草稿」+ 强免责，非法务意见
- 限流与配额必做，防止 API 成本失控

### 4.5 变现（P1～P2）

| 手段 | 说明 |
|------|------|
| Affiliate | 详情主按钮走联盟链接；记录点击 |
| 付费收录 / 置顶 | 运营字段 + 人工收款起步 |
| 广告 | AdSense / 直售位（流量起来后） |
| 会员 | 小工具额度 + 精选内容包 |

### 4.6 账号与运营基建（复用）

- 注册登录、资料、Admin、媒体上传、SEO、搜索
- 轻量：收藏；评论 / 关注非主路径

## 5. 核心数据对象（大纲）

| 对象 | 要点 |
|------|------|
| Tool | name, slug, category, tags, pricing, urls(官网/联盟), score, pros/cons, status, pin/weight |
| Category / Tag | 写作、绘画、视频、编程、办公等 |
| Deal | toolId, 文案, code, 起止时间, url, status |
| Article | 增加类型与 relatedToolIds |
| AiMiniTool | slug, prompt, model, quotas, enabled |
| AiRunLog | 用户、slug、用量、时间（配额与成本） |
| ClickLog（可简） | 工具 / Deal 外链点击 |

---

## 6. 关键路径

1. SEO / 分享 → 工具详情 → Affiliate 跳转  
2. 优惠页 → Deal → 跳转  
3. 评测文章 → 相关工具 → 详情 / 外链  
4. 小工具 → 生成 → 额度用尽 → 登录 / 会员  
5. 合作页 → 付费收录 → 运营上架  

---

## 7. 范围边界

### In（近端）

- 工具库 CRUD + 前台导航详情  
- 文章关联工具  
- Affiliate 链接与点击统计  
- Deal  
- 商品描述生成器 + 配额  
- 主导航改版、旧社区入口降权  

### Out（近端不做）

- 整体重构 / 换技术栈  
- 复杂商家入驻与自动分账  
- 合同正式审查结论  
- 重社交、私信、实时 Agent 平台  
- 多租户 SaaS

## 8. 成功标准（大纲级）

| 阶段 | 标准 |
|------|------|
| 导航 MVP | 可上架工具、分类浏览、详情外链可点并可统计 |
| 内容 | 至少若干评测文挂相关工具 |
| 小工具 | 商品描述可生成；日配额生效 |
| 变现准备 | Affiliate URL 可配置；置顶字段可用 |

## 9. 风险与约束

- LLM 成本：必须限流 / 配额 / 会员分层  
- 合规：简历少存；合同强免责  
- 焦点：先保证工具库持续更新，再堆小工具数量  
- 本文为暂定大纲，字段与品牌名变更时只改本文与 roadmap，避免再分叉多份 PRD
