## 1. 产品定位

**一句话：** 用对话快速找 AI，按分类逛成熟产品，站内直接试用实用工具；辅以评测与限时优惠。

**体验北极星：** 打开网站 → 像成熟 AI 产品一样对话或浏览 → 3 分钟内找到合适工具或完成一件小事（如写商品描述）。

| 层级 | 前台名称 | 路由 | 用户得到什么 |
|------|----------|------|--------------|
| **默认入口** | 聊天检索 | `/` | 问答 + 站内导流 + **模糊搜产品/评测**（可点结果）；技能在侧栏 |
| **双轨 A** | AI导航 | `/tools` | 市面成熟 AI 产品分门别类，详情可直达官网 |
| **双轨 B** | 聊天技能（侧栏） | `/` 内模式切换 | 文案 / 翻译 / 简历 / 视觉 / **内容总结** / 合同等，**对话框内完成** |
| **检索** | （并入聊天检索） | `/` | 不再单独设顶栏搜索框 |
| **辅** | AI评测 | `/articles` | 针对**具体产品**的评测文 / 体验帖 |
| **辅** | 限时优惠 | `/deals` | 近期有折扣或活动的 AI 产品 |
| **浏览** | 发现 | `/discover` | 热门产品、工具入口、精选评测一站浏览 |
| **说明** | 关于 | `/about` | 各模块能帮你什么；管理员联系方式 |
| **粘合** | 轻社交 | （散落） | 收藏、赞评；关注不进主导航 |

**品牌：** 顶栏「AI Tools Hub」进入聊天（与 `/` 一致）。

**不是什么：** 不是重社区；不是大而全 Agent 平台；不做合同正式审查结论；不把工程排期术语写进前台。

**视觉：** 深空底 + 青绿 / 电蓝光感，吸睛、偏成熟 AI 产品气质（见技术方案「视觉体系」）。

## 2. 目标用户与角色

| 角色 | 核心诉求 | 成功体验 |
|------|----------|----------|
| 访客 | 找产品、看评测与优惠、用聊天技能 | 不注册也能逛导航与评测；技能有基础额度 |
| 登录用户 | 更高额度、收藏、提交收录建议 | 个人中心清晰：额度 / 收藏 / 账号 |
| 会员（后期） | 更高额度、精选内容 | 付费价值可感知、可兑现 |
| 运营管理员 | 维护工具库、优惠、评测、用量 | Admin 能高效上下架与看数据 |
| 工具方 / 商家 | 付费收录、置顶、活动 | 先人工对接，后台字段可支撑报价 |

## 3. 信息架构（与线上一致）

```text
顶栏：聊天 | 发现 | AI导航 | AI评测 | 限时优惠 | 关于
品牌点击 → 聊天检索
（无顶栏搜索框；目录检索并入聊天检索模式）

/                 聊天检索（默认；含模糊搜产品/评测；左侧技能）
/discover         发现
/tools            AI导航列表
/tools/:slug      工具详情（P1）
/articles         AI评测列表
/articles/:id     评测详情
/deals            限时优惠
/about            关于（模块说明 + 联系电话）
/login /register  账号
/studio           个人中心
/admin            治理后台

（历史）/ai-tools/** 可保留兼容，不再作为主路径
```

**聊天侧栏技能（文档组含内容总结）：**

```text
对话   聊天检索（默认：问答 + 导流 + 模糊搜）
文本   文案写作 · 文本翻译 · 简历优化
视觉   图像生成 · 图片识别 · 视频理解
文档   内容总结（Word/Excel/PPT/PDF 等）· 合同助手
```

**能力双轨：** AI导航（外部产品库）∥ 聊天技能（站内办事，输入框闭环）；对外顶栏不单独放「AI工具」。

**降权保留：** `/projects`、关注列表等旧创作者路径可不删，但不进顶栏、不作为主叙事。

**文案原则：** 禁止「一期 / API / 底座 / 双轨 / Mock」等内部词；只写用户能得到什么。空态用「内容筹备中」等友好表述。

## 4. 功能需求（按用户价值）

### 4.1 聊天检索（默认首页）

| 能力 | 说明 |
|------|------|
| 对话式入口 | 左侧模式栏 + 主对话区；默认「聊天检索」 |
| 聊天检索 | 问答与站内导流；**模糊搜已收录 AI 产品与评测**，结果以可点击列表回复；后期接真模型 |
| 技能模式 | 文案写作 / 文本翻译 / 简历优化 / 图像生成 / 图片识别 / 视频理解 / **内容总结（Word·Excel·PPT·PDF 等）** / 合同助手 |
| 办事方式 | **一律在当前对话输入框完成**，不强制跳转独立表单页 |
| 意图理解 | 识别导流 / 搜索 / 办事类意图；办事引导切技能 |
| 检索入口 | **取消顶栏搜索框**；检索能力只在聊天检索模式 |
| 无重复入口 | 欢迎区不放与顶栏重复的导航按钮 |

### 4.2 AI导航（双轨 A）

| 能力 | 说明 |
|------|------|
| 分类浏览 | 写作、绘画、视频、编程、办公、对话等 |
| 筛选 / 排序 | 免费/订阅、中文、精选、热度等 |
| 详情 | 简介、评分摘要、优缺点、定价、官网 / 联盟 CTA |
| 运营 | 草稿 / 上架 / 下架、置顶、权重 |
| 点击 | 外链经跳转计数，可统计合作效果 |

### 4.3 聊天技能（双轨 B）

| 能力 | 说明 |
|------|------|
| 入口 | 聊天页左侧模式栏；各技能**在当前对话输入框完成**，不强制跳转表单页 |
| 统一运行 | `POST /api/ai-tools/{slug}/run`（优先流式）；模式 id 与 slug 对齐 |
| 配置化 | Prompt、模型、日配额、开关、文件类型白名单 |
| 文本类 | 文案写作（可先上）；翻译；简历优化（少持久化） |
| 视觉类 | 图像生成；图片识别；视频理解 |
| 文档类 | **内容总结**（Word / Excel / PPT / PDF 等上传或粘贴）；合同助手（仅风险提示草稿，非法务意见） |
| 转化 | 访客低额度 → 登录 / 会员提高额度 |

### 4.4 目录检索（并入聊天检索）

| 能力 | 说明 |
|------|------|
| 范围 | 仅 **AI 产品** + **AI 评测**（不做闲聊、不生成） |
| 体验 | 对话气泡内可点击列表 → 详情或导航 |
| 入口 | 仅聊天检索模式；**无顶栏搜索** |
| 演进 | 当前关键词；接口形状预留，可换成语义检索（E1） |

### 4.5 AI评测

- 复用文章模块；定位为**具体产品的评测 / 体验帖**
- 可关联多个 Tool；文内展示工具卡片 → 详情 / 外链
- 列表支持最新 / 热度；SEO 基础 meta

### 4.6 限时优惠

- 关联工具；文案、优惠码、有效期、跳转
- 仅展示进行中；过期自动隐藏或不可点
- 发现页可有入口卡片

### 4.7 发现

- 热门 AI 产品、聊天技能入口、精选评测
- 不重复顶栏大按钮堆；分类细节在 AI导航内完成

### 4.8 关于与联系

- 只介绍各业务模块对用户的便利
- 联系：**仅网站管理员手机** `13476270359`
- 不展示技术栈、仓库名、排期

### 4.9 账号、个人中心与治理

- 开放注册 / 登录；资料与安全设置
- 个人中心：额度、收藏、（可选）投稿建议；评测作者能力可保留在工作室
- Admin：Tool / Category / Deal / AiMiniTool / 点击与用量 / 用户与内容治理

### 4.10 变现（成熟产品必规划）

| 手段 | 用户侧感受 | 运营侧 |
|------|------------|--------|
| Affiliate | 详情「去官网」顺畅 | 可配置联盟链 + 点击统计 |
| 付费收录 / 置顶 | 导航里更显眼 | 字段 + 人工收款起步 |
| 会员 | 聊天技能更好用 | 额度与权益可配置 |
| 广告 | 弱打扰 | 流量起来后再接 |

### 4.11 轻社交

- 收藏工具；评测可赞评（登录）
- 关注不进主导航，避免定位打架

## 6. 关键路径（成熟产品主路径）

1. **打开站点 → 聊天** →「找绘画 AI」→ AI导航 → 详情 → 外链  
2. 聊天侧栏 → **文案写作 / 内容总结** 等 → 对话框内生成 → 额度用尽 → 登录 / 会员  
3. AI评测 → 相关工具卡片 → 详情 / 外链  
4. 限时优惠 → Deal → 跳转  
5. 关于 → 电话联系合作 → 运营上架

## 7. 范围边界

### In（近端必须逼近「好用」）

- 默认聊天可用且意图跳转靠谱（可先规则，后 LLM）  
- AI导航真实数据：分类、列表、详情、外链  
- 聊天技能：文案写作先上线；内容总结等按排期接入（含文档上传）  
- 技能均在对话框完成 + 配额 +（优先）流式  
- AI评测可挂工具；限时优惠可运营  
- Affiliate 点击可统计；前台文案与视觉统一 AI 气质  
- 移动端主路径可用  

### Out（近端不做）

- 整体换技术栈 / 重写前后端  
- 复杂商家入驻与自动分账  
- 合同正式审查结论  
- 重社交、实时多 Agent 平台  
- 多租户 SaaS  
- 技能再拆独立顶栏入口

## 8. 成功标准（产品级）

| 维度 | 标准 |
|------|------|
| 入口 | 新访客默认进聊天，能通过一句话到达正确板块 |
| 导航 | 运营可上架 ≥1 个分类下的真实产品；详情外链可点可统计 |
| 技能 | 文案写作可在对话内稳定生成；日配额挡住滥用 |
| 内容 | ≥若干篇评测关联真实工具 |
| 优惠 | 至少可配置并展示进行中优惠 |
| 体验 | 文案无工程黑话；视觉统一；手机可完成主路径 |
| 信任 | 关于页清晰；联系方式可达 |

## 9. 风险与约束

| 风险 | 应对 |
|------|------|
| LLM 成本 | 配额、限流、会员分层、可关停单技能 |
| 幻觉 / 乱跳 | 聊天意图白名单；荐工具需可解释 |
| 隐私 | 简历 / 合同 / 上传文档少存或不存；日志脱敏；有留存期限 |
| 文档解析 | Word/Excel/PPT/PDF 解析失败要可读提示；限制大小与页数 |
| 焦点涣散 | P1 先导航 + 一文案技能，再铺内容总结等 |
| 旧代码干扰 | Project / Follow 降权，避免主导航回潮 |

增强能力（语义搜 E1、荐工具 E2、摘要 E3）见路线图，**不进前台文案**。

## 11. 开发就绪声明（Outline 0.5）

以下已对齐，可进入 **P1 正式开发**：

1. 产品定位、顶栏 IA、默认聊天 + 侧栏技能（含**内容总结**）已定。  
2. 目录检索已并入聊天检索（无顶栏搜索）。  
3. 前台文案 / AI 视觉 / 关于与联系已落地。  
4. 旧 Project / Follow 降权策略已定。  
5. 技术选型与部署 / CI/CD 可复用。  

**P1 建议开工顺序：** Tool 域（库表 + Admin + 列表详情）→ 文案写作接 AiClient + 配额 → 聊天意图加固 → 发现接真数据。
